## Model-specific extract — Bell 407 IBF wash note + helicopter baseline

**Source:** `manuals/bell-407-ibf-aircraft-washing-note.md` (+ `faa-info16005-automotive-detailers.md`, `faa-ac-43-4b-cleaning-washing.md`; fetched 2026-09-14).

### Explicit
- If IBF/IVF installed: **protect or remove filters** before wash — HP spray damages media; solvents strip filter oil.
- Prefer mild soap, soft tools; avoid HP wash into hubs/electronics (Bell SPM Ch.5 is OEM-controlled — sources-wanted).
- Prep/lube/inspect/document per InFO16005 when wash is part of CPCP.

### U-turn
Soft wash recommended → aviation soap + microfiber OK if not banned. HP into IBF = forbid.


## Transparent plastics — FAA AC 43.13-1B

See `manuals/faa-ac-43-13-1b-transparent-plastics-cleaning-part1.md`. Mild soap + water; no glass cleaner/acetone/alcohol/fuel on acrylic; no dry wiping; thin wax after clean.
