## Model-specific extract — Cirrus SR22 POH Section 8

**Source:** `manuals/cirrus-sr22-poh-section8-cleaning.md` (fetched 2026-09-14).

### Explicit / strong guidance
- Mild soap + water; cover static ports; silicone-free wax; soft cloth/chamois.
- **Do not wax TKS/Ice Protection porous leading-edge panels.**
- Acrylic: solvent-free antistatic cleaner; no gasoline/alcohol/benzene/CCl4/thinner/acetone/glass sprays; no paper towels; no dry rub; up-down wipe only.
- POH product table lists Prist, carnauba, RejeX, XL-100, Stoddard, etc. (recommendations).
- Graphics pressure wash limits if used: <2000 psi, perpendicular, ≥1 ft.

### U-turn
Cotton/chamois → clean microfiber OK if not banned. TKS no-wax = forbid.
