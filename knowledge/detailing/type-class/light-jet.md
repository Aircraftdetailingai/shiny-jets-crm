# Light jet — aluminum / composite

## Type-class profile (generic)

**Label:** GENERIC — confirm against this aircraft’s AMM (Citation / Phenom / HondaJet / Eclipse class).

### Typical notes
- Often Zone wash / CPCP wash intervals by corrosion exposure (see Citation 525A discretionary wash example)
- Leading-edge boots or TKS on some types — product compatibility critical
- Acrylic cabin windows on many light jets; windshield may be glass laminated — **verify**
- Static wicks, antennas, flush ports — no aggressive compounding
- Skydrol / hydraulic fluid attack on paint — neutralize per OEM ASAP

### Detailing defaults
- No high-pressure intrusion into gear wells / bay seals
- Prefer OEM-listed cleaners when stated; otherwise mild soap + U-turn for better modern soap if not banned
- Stop for bond-line, composite delamination, or window crazing
