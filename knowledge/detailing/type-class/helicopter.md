# Helicopter — exterior care

## Type-class profile (generic)

**Label:** GENERIC — confirm against this rotorcraft’s RFM/AMM.

### Typical notes
- Bubble / chin windows often **acrylic** — same no-dry-wipe, no-glass-cleaner rules
- Main/tail rotor blades — OEM cleaning only; balancing/track is maintenance
- Hub, dampers, pitch links — keep solvents/pressure wash away unless OEM procedure
- Exhaust soot on Fenestron/tail boom common
- Many types prohibit high-pressure wash near bearings and electrical

### Detailing defaults
Mild soap; soft cloths; protect pitot/static/AOA; no abrasive on plexi; coordinate with maintenance before degreasing transmission areas.
