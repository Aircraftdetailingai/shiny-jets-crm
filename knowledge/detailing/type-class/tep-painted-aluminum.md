# Twin-engine piston — painted aluminum

## Type-class profile (generic)

**Label:** GENERIC — confirm against this aircraft’s current MM/POH.

### Typical construction
- Twin piston, painted aluminum; acrylic cabin windows
- More lubrication points, gear doors, nacelles — wash technique matters

### Detailing defaults
- Follow Beechcraft-class wash discipline when applicable: lubricate hinges/gear **before** wash; tape pitot/static/intakes; **no high-pressure washers**; mild liquid soap + cellulose sponge; wash underside-out to reduce streaking; clear drain holes; re-lube after
- Acrylic care same as SEP (FAA AC 43.13-1B)
- Protect avionics bay / inverter louvers from overspray

### U-turn
Mild soap + sponge recommended → better aviation wash chemicals OK if not forbidden. Soft cloth → microfiber OK if grit-free and not banned.
