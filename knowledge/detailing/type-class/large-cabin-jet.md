# Large-cabin / heavy jet & VIP airliner derivatives

## Type-class profile (generic)

**Label:** GENERIC — confirm against this aircraft’s AMM and operator GMM.

### Typical notes
- Composite fairings + aluminum; tall verticals; extensive antennas/static wicks
- Wash often per operator CPCP / corrosion program — not ad-hoc
- Windows frequently acrylic cabin + complex windshields — verify polish approval
- Hydraulic fluid (Skydrol) damage common around belly/gear — strip and neutralize ASAP per OEM
- Never treat as “big car detail” — access stands, fall protection, and OEM chemistry matter

### Detailing defaults
Coordinate with maintenance for open panels, deferred items, and approved cleaners list. Escalate structural/paint system failure.
