# Single-engine piston — painted aluminum

## Type-class profile (generic)

**Label:** GENERIC — confirm against this aircraft’s current POH/PIM/AMM before work.

### Typical construction
- Aluminum airframe, painted polyurethane/acrylic enamel finishes
- **Acrylic** windshield and cabin windows (not automotive glass)
- Often fixed or retractable gear; spinner and prop brightwork or painted

### Detailing defaults (industry + FAA AC 43.13-1B + common PIM language)
- Wash: mild soap + water; soft grit-free cloth/sponge; rinse; dry with chamois/soft cloth
- Avoid harsh/abrasive detergents; avoid dry-wiping acrylic
- Acrylic bans (typical explicit): gasoline, benzene, alcohol, acetone, fire-extinguisher fluid, anti-ice fluid, lacquer thinner, glass cleaner
- Paint: Stoddard solvent sparingly for oil/grease; wax/seal regularly especially coastal/salt
- Prop: wipe; alkaline cleaners often discouraged in PIMs; dress nicks via maintenance not detailing
- High-pressure wash: generally discouraged (grease washout, seam intrusion) — treat as prohibited unless OEM explicitly allows

### U-turn
Terry/flannel recommended in many PIMs → clean microfiber allowed if not prohibited. Mild soap recommended → modern aviation-safe wash soap OK if chemistry not banned.
