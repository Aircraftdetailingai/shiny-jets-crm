# Midsize / super-mid business jet

## Type-class profile (generic)

**Label:** GENERIC — confirm against this aircraft’s AMM.

### Typical notes
- Larger acrylic cabin windows; polished or painted leading edges; possible thrust-reverser areas with heat/soot
- Frequent hangar queens still need CPCP-aware wash cadence
- Brightwork (if any) and stainless hinges — cut-level quoting
- Interior: leather, veneer, carpet — use SOP library; no saturate solvents

### Detailing defaults
Same wash discipline as light jet with longer rinse/dry times and more drain-hole discipline. Prefer model AMM Chapter 12 servicing when available.
