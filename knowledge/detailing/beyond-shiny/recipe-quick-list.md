# Beyond Shiny (Brett Berry) — Recipe quick list (book era)

Source: digest of Brett Berry's book *Beyond Shiny – The Shiny Jets Approach to Aircraft Detailing* (not the full text). [Lxxx] = line refs in the privately stored full text. Products are spelled as in the book.

**Precedence:** Brett's shop recipes (stored privately server-side; Sep 28 2026) override this book for paint correction. The book's medium-oxidation recipe (Rupes blue wool + Fly Shiny Pro Cut) is **superseded** for current single-stage work — use the shop-recipe excerpt when Detailing AI provides it. The book does **not** cover clearcoat — use the shop recipe for clearcoat. Always ask single-stage vs clearcoat first. For brightwork and carpet grease/ink, the shop recipes also apply.
**Safety:** the book's safety / FAA cautions always apply — see `beyond-shiny/safety-cautions.md`. Never invent chemical mixes or dilutions; only repeat ratios stated here, otherwise say "follow the manufacturer label".

## 13. Top recipe / procedure quick list (pad + product + tool)
1. Medium oxidation, single-stage paint: **DA + Rupes blue wool pad + Fly Shiny Pro Cut**, one step. [L944]
  - ⚠ **Superseded for current shop work** → Brett's single-stage shop recipe (private; light/moderate and heavy oxidation steps).
2. Heavy oxidation: **DA + Rupes blue wool + Fly Shiny Pro Cut** in small sections, **or rotary + wool pad + compound** (e.g. **Fly Shiny Pro Polish**, long working time) at ~1,200 RPM, light pressure, 1"/sec, crosshatch. [L948, L912, L962]
  - ⚠ **Superseded for current shop work** → Brett's single-stage shop recipe (private; light/moderate and heavy oxidation steps).
3. Light oxidation: **DA + foam pad + Fly Shiny Pro Polish** (or a light polish or polishing wax). [L940-941, L988]
  - ⚠ Current light-to-moderate single-stage work and all clearcoat work → Brett's shop recipe (private).
4. Oxidation check: **50/50 IPA/water** wipe (rotary); IPA wipe between test patches. [L965, L935]
5. Wax/seal: **DA (speed 4-5) + foam pad + RejeX**, ~4 pea-sized drops per section, 20-min dwell, remove with Motherfluffer, clean the pad with the Tornador (air only). [L1093-1101]
6. Ceramic layer 1: **DA (speed 2) + foam interface pad + Autofiber saver applicator sheet + Fly Shiny Pro**, 20-30 drops to prime, crosshatch. Prep: IPA + **Fly Shiny Pro Bond Enhancer**. [L1263, L1268]
7. Ceramic layer 2: **Saver Microfiber Applicator + Fly Shiny Pro** by hand, ultra-plush removal. [L1234, L1277]
8. Topper/recharge: **damp edgeless multi-purpose towel (10 sprays, then 1-2) + Fly Shiny Air Guard**, dry ultra-plush wipe. Every 6 months after **Fly Shiny Ceramic Prep Spray**. [L1140, L1286, L1291]
9. Brightwork cut: **rotary 800-900 RPM + (blended) wool polishing pad + cutting polish** (Fly Shiny Top Cut / Revitalizer; F7, G6, Shiny Jets Cutting Polish, Nuvite). Rake every application, stay under 150°F, repeat 3-4 times. [L1388-1391, L1403]
  - ⚠ Current brightwork one-step → Brett's shop recipe (private). Book cautions (under 150°F, tape/plastic-sheet, PPE) still apply.
10. Brightwork finish: **random orbital + cotton velour bonnet + Fly Shiny Reflection Fine Polish** (or Nuvite S / Shiny Jets Finisher), 2-3 times. [L1397-1398, L1338]
11. Brightwork protect: **90% IPA + ultra-plush prep → Granitize X20-18 applicator, 2-ft sections, ultra-plush wipe, 3 coats.** [L1408, L1414-1419]
12. Black BFG boots: **Prep + Magic Eraser (10-15 min wet) → terry flush → Agemaster ×3 (10-15 min apart, 24 h cure) → Shinemaster ×3 (~10 min apart) → ICEX II (level ~10 min, wipe off with multi-purpose microfiber).** [L1546-1574]
13. Acrylic windows: **heavy-cut compound + Rupes blue wool (3" then 5-6", DA 4.5) → firm foam cutting pad → yellow foam + polish → finishing pad + fine polish**, 3 passes each. Prep with **1:3 90% IPA:water**, protect with **Fly Shiny Pro** (10-15 drops) or **Air Guard**. [L1663-1667, L1697-1705]
14. Leather: **Scrub Ninja + Colourloc Mild Leather cleaner**, multi-purpose microfiber dry. Deep: **Magic Eraser + Colourloc Strong Leather Cleaner**. Condition: **Elephant Leather Preserver + applicator, buff.** [L1852-1854, L1861, L1880]
15. Carpet: **Wool Perfect pre-spray (<140°F, pump sprayer) → rotary ~600 RPM + wool carpet bonnet → heated extractor with Wool Zone acid rinse → carpet fan.** Coffee: **Bridgepoint Coffee Stain Remover 1 scoop/quart hot water.** Oil: **Citrus Solv 1-2 oz/gal**, MEK only as a coin-sized last resort. Wine: **Stain Magic for WOOL + CSS (3 water : 1 CSS rinse)**. [L2017-2027, L2055, L2047-2049, L2060-2062]
  - ⚠ Carpet grease / ink / Sharpie → current method is Brett's shop recipe (private). MEK limits from the book still apply if MEK is ever used.
16. Dry wash oil/soot/bugs: **Fly Shiny Dissolver on cotton terry** (oil/Skydrol) → **degreaser-misted damp Dreadnaught** (soot) → **Fly Shiny Bug Blitz + dry wash overspray** (bugs) → **Fly Shiny Static Gaurd Dry Wash + Dreadnaught 20"x40"** from a pressurized keg. [L569, L575, L604, L598-599]
